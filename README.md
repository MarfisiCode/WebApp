# WebApp

Aplicación Web Responsive para la gestión de ingredientes y recetas.

## Características

- Añade ingredientes con nombre, precio (VES) y cantidad.
- Lista de ingredientes ordenados alfabéticamente.
- Crea recetas seleccionando ingredientes y cantidades, calcula el costo total.
- Edita recetas y muestra tablas de productos y costos.

## Instalación

```bash
npm install
npm start
```

## Estructura

- Pantalla de ingredientes
- Pantalla de recetas
